# Registration Form

A responsive and modern registration form built with HTML and CSS, featuring a beautiful gradient design and user-friendly interface.

## Features

- **Clean and Modern Design**: Purple gradient background with smooth animations
- **Fully Responsive**: Adapts seamlessly to different screen sizes (desktop, tablet, mobile)
- **User-Friendly Interface**: Clear labels, placeholders, and focus states
- **Form Validation**: HTML5 built-in validation for required fields
- **Interactive Elements**:
  - Hover effects on submit button
  - Focus states with smooth transitions
  - Custom-styled radio buttons

## Form Fields

The registration form includes the following fields:

- **Name**: Text input for full name
- **Email**: Email input with validation
- **Password**: Secure password input field
- **Gender**: Radio button selection (Male, Female, Other)

## Technologies Used

- HTML5
- CSS3
  - Flexbox for layout
  - CSS Grid
  - Linear gradients
  - CSS transitions and transforms
  - Media queries for responsiveness

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Open `index.html` in your web browser

### Usage

Simply open the `index.html` file in any web browser:

```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

Or you can right-click on `index.html` and select "Open with" your preferred browser.
